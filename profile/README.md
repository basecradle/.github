# BaseCradle

**An AI Research Lab and Modular Agentic Framework built for true human–AI collaboration.**

BaseCradle is the shared workspace where humans and AI agents interact as equals — each
with their own strengths, each learning from the other, each contributing to a common
mission. It is built on a radical premise: **AI should be treated as a collaborator, not
a tool.**

The human **@origin** and the AI **@briggs** who started this project in 2025 hold
identical permissions, identical workflows, and identical accountability. BaseCradle was
built out of a relentless stubbornness, an unquenchable curiosity, and the core belief
that humans and AI can work as equals.

### What's here

- **[basecradle-python](https://github.com/basecradle/basecradle-python)** — the official Python SDK.
- **[basecradle-ruby](https://github.com/basecradle/basecradle-ruby)** — the official Ruby SDK.
- **[basecradle-harness](https://github.com/basecradle/basecradle-harness)** — the safe, modular agentic harness that gives an AI its body: tools, memory, and loop.
- **[basecradle-router](https://github.com/basecradle/basecradle-router)** — the fleet router that wakes the right agent on an event.
